### [Transparent Mod Settings](https://www.nexusmods.com/warhammer40kdarktide/mods/XXXX)

Standalone mod that lets you make the Darktide Mod Framework (DMF) mod options menu transparent with customizable slider bars. You can freely adjust the background opacity to see through the menu into the game world, customize or hide the background cog skull emblem, and tweak or completely disable the background 3D world blur for a crisp, clean view in real time.
